## Panel d: reading the composition bars

Three stacked bars per event — parent A, parent B, and the coalesced community.
Species in the coalesced bar are coloured by where they came from: present in A
only, in B only, in both, or in neither.

Representative events are chosen deterministically rather than by hand:
Dominance is the Base-medium event with the highest angular asymmetry;
Restructuring is the one with the largest abundance of species present in
neither parent.

Restructuring is selected on novelty rather than on lowest retention because the
experimental parental communities are drawn from a shared 54-isolate pool and
overlap heavily. The lowest-retention event turns out to be 85% species shared
between both parents, which renders as one flat colour. The selected events
contrast cleanly:

| Event | A only | B only | shared | novel |
|---|---|---|---|---|
| Dominance (P5-11) | 0.0% | 38.0% | 60.9% | 1.1% |
| Restructuring (P5-43) | 0.0% | 4.8% | 68.6% | 26.6% |

## Panels e and f: reproduction

Base medium, n = 88: Dominance 63.6%, Mixture 3.4%, Restructuring 33.0%.

Published: n = 83, Dominance 65%, Restructuring 31%, Mixture 4%.

The five-event gap is the same quality-control filter discussed in
[`../fig4/README.md`](../fig4/README.md), which is not yet part of the shared
library. Fractions agree to within about 2 percentage points.

Grey points in panel e are the same events with the two parental labels
swapped; the map has no intrinsic parent ordering.
