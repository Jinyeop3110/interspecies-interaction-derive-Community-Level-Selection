## Panel d is not covered

Panel d shows stacked relative abundance across the seven growth-dilution
cycles for three representative coalescence events — two Community-Level
Selection, one Restructuring — with the parental time courses feeding into the
coalesced one.

It requires time-resolved composition data. The archived sequence tables carry
only the final timepoint (`Timepoint == "F"` for every sample in
`Metadata.xlsx`), so the panel cannot be regenerated from the deposited data.
The per-cycle sequencing behind it is not part of the archive.

## Panel e: reproduction

Exact, with the quality-control exclusions applied (the default).

| | Published | This code |
|---|---|---|
| Base *n* | 83 | 83 |
| Dominance | 65% (n = 54) | 65.1% |
| Restructuring | 31% (n = 26) | 31.3% |
| Mixture | 4% (n = 3) | 3.6% |

Grey points are the same events with the two parental labels swapped; the map
has no intrinsic parent ordering.

Marker shape encodes the initial species-pool size as the caption specifies —
circles for 6 species, squares for 12, triangles for 24 — with marker opacity
deepening with pool size, and the map frame carries the published furniture:
faint reference arcs, dashed inner and outer arcs, dashed Dominance/Mixture
rays between them, and dashed axis lines.
